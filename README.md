## 打开方式

- 本仓库为 GitHub Pages 托管；访问 `https://tsunami606.github.io/pear-pixel-farm/` 即玩（`index.html` 单文件、离线零依赖，评委无需任何账号或权限）。

- 首次打开有约 1 秒素材加载；游戏进度保存在浏览器本地（localStorage），与账号无关。

## 快速体验路径（评委版·约 3 分钟）

1. 开场 →「建造禽舍」（送 100 金币）→ 挑一块草地摆放 → 迎接小鸭；
2. 底部「学习」答题赚金币（每题 +5，答对即入账）→「商店·饲料」买普通饲料（4 金币/份）→ 连喂小鸭 4~5 次（第 4 份长大就绪、再喂 1 份开工；每份间隔约 5 秒）→ **教学加速：30 秒出首蛋**；
3. 收取**第一枚鸭蛋** → 兔舍蓝图 + 农田开张（梨宝送你第一颗花椰菜种子）；
4. 点右下角田块 → **选种子 → 绿色格子预览 → 点下种**；点梨宝 → 委托浇水（先答对一道题）；
5. 3~4 分钟后作物长大 → 委托收割 →「背包」卖钱 → 复种。
6. 其他亮点：池塘**钓鱼台**（限时答题）、猫狗宠物、动物花色收集、整理模式拖放。
